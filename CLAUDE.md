# Outlines (Project X) — project rules

The game is called **Outlines**; "Project X" is the repository and code name
(the `project-x-vN` cache key stays).

Work out a mystery place from clues, then draw its outline from memory.
Guessing early earns base points (5 down to 1); drawing accurately multiplies them: the multiplier is the accuracy (70% = 70x, perfect = 100x).

**Project X runs on the Bidding Wars shell.** The menu, sheets, settings, record,
privacy, setup, sealed-bar results, 3D globe, sounds (`sound.js`), motion (`fx.js`),
platform layer (`platform.js`), service worker and stylesheet (`app.css`) were copied
from `biddingwars/bidding-wars` and keep its conventions. Only the game is new.
When Bidding Wars improves its shell, port the change here by hand.

## Flat file layout (as in Bidding Wars)
Everything the game loads sits flat at the repo root and is referenced by plain
relative paths: `index.html`, `app.css`, `app.js`, `strings.js`, `engine.js`,
`packs.js`, `pack-countries.js`, `pack-states.js`, `globe.js`, `us-view.js`,
`us-map.js`, `platform.js`, `sound.js`, `fx.js`, `sw.js`, `manifest.json`, images.
Dev-only folders: `engine/` (engine source), `packs/` (pack sources and generated
outlines), `tools/`, `tests/`, `docs/`. The game never references them.

## Generated files — rebuild, never edit
- `engine.js` ← `engine/*.js` (ES modules, unit-tested): `node tools/make-engine.mjs`
- `pack-countries.js`, `pack-states.js` ← `packs/<id>/pack.js` + `outlines.js`: `node tools/make-packs.mjs`
- `npm run build` does both; `tests/shell.test.js` fails if either is stale.

## `sw.js` — bump `CACHE` on every deploy that touches a cached file
`const CACHE = 'project-x-v16'` and `CONFIG.version` in `platform.js` must move
together (the test checks). Without the bump, installed apps never see the change.

## Clues
Each place has a pool of clues in 5 tiers (1 = hardest, 5 = gives it away); the World
pack has 20 per country, 4 per tier. Each round draws one per tier (`pickClues`, seeded),
so a place reads differently every game. Every tier-5 clue must identify its place on its
own (the validator checks).

Clues are placed by how many of the 196 countries they fit (`assignTiers` in
`packs/world/auto.js`): tier 1 ≈ 60, tier 2 ≈ 20, tier 3 ≈ 7, tier 4 ≈ 2–3, tier 5 = 1.
Clues fitting more than 100 countries ("It is a republic") are not used, and a give-away
never comes before tier 4. Hand-written clues stay, except template clues that are far too
general or give the place away early. `tests/pack.test.js` checks the limits.
Every clue has a test the bot can check: computed clues (name letters and initials, size
ranks, latitude bands) carry real tests on English-name facts; only hand-written sentences
and the scrambled name fall back to a tag (they name the place). Name clues are used only
when they say the same in all thirteen languages, and one that singles a place out in any
language comes at tier 4 at the earliest. The bot rules out a place unless its facts show
a clue to be true (facts only the 20 hand-written countries have cannot keep others in).
Within one game no clue sentence is shown twice while its tier has another one, and places
from the player's recent games (kept in `record:v1`) are dealt last; every game still draws
from at least half of the pool at random.

World pack = all 196 countries (193 UN members + Vatican City, Kosovo, Taiwan):
- `packs/world/source.js` — country data from world-countries (ODbL), generated by
  `tools/build-world-source.mjs`. Never edit by hand.
- `packs/world/lists.js` — hand-kept facts the data lacks (drive side, monarchies, EU,
  Olympic hosts, World Cup winners) and capital corrections.
- `packs/world/auto.js` — builds facts and a 20-clue pool for every country from the above
  plus the outlines (latitudes, lines crossed, east/west of Greenwich).
- 20 countries have hand-written pools (`packs/world/clues-*.js`) and fun facts
  (`base.js`); they win over the automatic ones.
- Templates and their words in five languages: `packs/world/templates.js`.
- Fun facts ("Did you know?") for the other 176: `packs/world/facts-*.js`, by region;
  a test checks every country has one in all five languages.
- Difficulty: beginner (tier 1), standard (≤2), expert (≤3), master (all 196).

US States pack = all 50 states, built the same way (`packs/us-states/`):
- `data.js` — hand-kept facts for all 50 (region, neighbours, coasts, borders, capital, largest
  city, nickname, admission year, 2020 population rank, land-area rank, capital time zone,
  side of the Mississippi, highest point) and, for the 40 added states, names, a landmark and
  a fun fact in the first five languages. `tests/states.test.js` checks the facts agree.
- `auto.js` — a pool of 15 clues per state, 3 per tier, placed by how many of the 50 they fit
  (tier 1 ≈ 16, tier 2 ≈ 7, tier 3 ≈ 3–4, tier 4 ≈ 1–2, tier 5 = 1). Texts are complete in all
  thirteen languages: the other eight come from the `us` section of `packs/i18n/<lang>.js`
  (`frame.<name>`, `XX.names`, `landmark.XX`, `XX.fact`) and city names from `city`.
- The 10 starter states keep their hand-written clues; one that gives the state away moves to tier 5.
- Postal codes ("TX") are accepted as names; equal matches list the better-known place first.
- Difficulty: beginner (12 states), standard (26), expert (41), master (all 50).

## House rules carried over
- No network at runtime; every asset bundled; no CDN, no remote code.
- Privacy: no accounts, analytics or SDKs. Stored on device only: `lang:v1`,
  `theme:v1`, `settings:v1`, `record:v1`, `name:v1`, and `log:v1` only when the player
  switches on "Record my games". "Delete all data" removes all.

## Beta testing (game log, as in Bidding Wars)
Settings → "Record my games" (off by default) keeps a log on the device (`engine/gamelog.js`,
`log:v1`): per game the clues shown, guesses, action timings, drawings (≤80 points per
ring) with the judge's fit, scores, unrecognised typed names, plus app errors. No names.
The player exports it (Share or Copy) and sends it; `node tools/analyze-log.mjs <file>
[--svg dir]` prints the report and draws each drawing over the real outline.
Guide for testers: `docs/BETA-TESTING.md`.
- Thirteen languages: en, de, it, es, fr, pt (Brazil), id, zh (Simplified), hi, ja, ko,
  ar (right to left: `dir="rtl"` is set from `LANGS` in `strings.js`), th. Every word in all
  thirteen; the tests fail on any gap.
  - UI words: `strings.js` (`STR` for the first five, `STRL` for the other eight).
  - Pack text: the first five live in the pack sources; the other eight in
    `packs/i18n/<lang>.js` (+ `<lang>-facts.js`), keyed by the text's place in the pack
    (layout in `packs/i18n/localize.js`). `node tools/i18n.mjs` lists anything missing.
  - Country names in the added languages come from Unicode CLDR (`Intl.DisplayNames`,
    at build time) with a few fixes in `packs/world/pack.js`.
  - Name clues (letters, initials, scrambled name) use the English name in non-Latin
    scripts, and say so.
  - Use CSS logical properties (`inset-inline-start`, `text-align:start`) so Arabic mirrors.
- The engine is pure: no DOM, storage or timers (`tests/purity.test.js`).
- Scoring is tuned by simulation (`npm run sim`, `npm run tune`), never by feel. The judge
  forgives a tilt of up to ±50° (beta logs showed upright drawings of diagonal countries);
  `tests/fixtures/beta-drawings.json` keeps those drawings as a regression test.
